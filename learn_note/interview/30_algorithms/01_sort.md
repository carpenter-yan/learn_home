# 排序
## 什么是选择排序？请用 java 代码给出简单示例
### 一、选择排序原理
1. 找到数组中最小的元素，将它和数组第1个元素交换
2. 找到剩余元素中最小的，将它和数组第2个元素交换
3. 如此反复，直到将整个数组排序
### 二、Java 完整代码示例
```
public class SelectionSort {
    public static void selectionSort(int[] arr) {
    if (arr == null || arr.length <= 1) {
        return;
    }
    int len = arr.length;
    //i 代表已排序区间末尾，每轮确定arr[i]是剩余最小值
    for (int i = 0; i < len - 1; i++) {
        // 假设未排序区间第一个是最小值下标
        int minIndex = i;
        // 遍历未排序区间，找真正最小值下标
        for (int j = i + 1; j < len; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        // 最小值和当前 i 位置交换
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}
```
### 三、面试口述精简版
选择排序每一轮在剩余未排序部分找出最小值，放到当前头部；全程必须完整遍历找最小值，不能像冒泡一样提前退出；
只交换一次元素，但属于不稳定排序，业务中极少使用，仅作基础算法理解。

## 什么是插入排序？
### 一、插入排序原理类比整理扑克牌：把数组分为已排序区和未排序区。
通常和人们整理桥牌时的方法是一张一张的来，将每一张牌插入到其他已经有序的牌中的适当位置
- 默认第一个元素是有序区；
- 依次取出未排序区第一个元素，向前遍历有序区，找到合适位置插入；
- 比当前元素大的元素统一后移，腾出空位放入当前值。
  时间复杂度：
  最好（数组已有序）O(n)，平均/最坏 O(n^2)
  空间：O(1)原地排序
  稳定性：稳定排序（相等元素不交换，相对顺序不变）
  优势：数据接近有序时效率极高，工程上小数组常用插入排序优化快排
### 二、Java 代码示例
```
public class InsertSort {
    public static void insertSort(int[] arr) {
        if (arr == null || arr.length <= 1) {
            return;
        }
        int len = arr.length;
        // i是未排序区间第一个元素，从第二个开始
        for (int i = 1; i < len; i++) {
            int cur = arr[i]; // 当前待插入元素
            int j = i - 1;    // 有序区末尾下标
            // 向前遍历有序区，大于cur就后移
            while (j >= 0 && arr[j] > cur) {
                arr[j + 1] = arr[j];
                j--;
            }
            // 找到插入位置 j+1
            arr[j + 1] = cur;
        }
    }
}
```
### 三、面试口述精简版
插入排序像插扑克牌，逐个把未排序元素插入前面有序区间；数组越接近有序速度越快，稳定排序。
业务很少单独手写，但快排底层递归到小数组时会改用插入排序做优化。

## 什么是冒泡排序？
### 一、冒泡排序原理
- 遍历数组，相邻两个元素两两对比，如果前一个>后一个，交换两者；
- 每一轮遍历结束后，当前未排序区间最大的元素会 “冒泡” 到尾部；
- 优化：如果某一轮全程没有发生交换，说明数组已经有序，直接退出循环。

时间复杂度：平均/最坏O(n^2)，最优（已有序）O(n)
稳定性：稳定排序（相等元素不交换，相对顺序不变）
### 二、Java 完整示例（带优化）
```
public static void bubbleSort(int[] arr) {
    if (arr == null || arr.length <= 1) {
        return;
    }
    int len = arr.length;
    // 外层控制轮次，每轮确定一个最大值放到末尾
    for (int i = 0; i < len - 1; i++) {
        boolean swapFlag = false; // 标记本轮是否发生交换
        // 内层只遍历未排序区间，len-1-i 后面已经排好序
        for (int j = 0; j < len - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换相邻元素
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapFlag = true;
            }
        }
        // 本轮无交换，数组已有序，提前结束
        if (!swapFlag) {
            break;
        }
    }
}
```
### 三、面试口述精简版
冒泡排序就是相邻元素依次比较逆序交换，每一轮把最大元素移到数组末尾；通过交换标记优化有序数组场景，属于稳定的平方级排序，
只适合少量数据排序，业务代码基本不用，主要用于理解基础排序思想。

#### 补充：为什么不稳定？举例
数组 [2, 2, 1] 第一轮找到最小值 1，和第一个 2 交换 → [1, 2, 2] 原本两个2的相对顺序颠倒，因此不稳定。

## 快速排序

二、分治/堆 O (n log n)（工程主流，面试重点）
快速排序 Quick Sort【必考】
选基准，小于基准放左、大于放右，递归左右。
不稳定；平均 O (nlogn)，最坏 O (n²)（有序数组）；
优化：随机基准、三数取中。

归并排序 Merge Sort
分治拆分到单个元素，再有序合并两个有序数组。
稳定；永远 O (nlogn)；需要额外数组空间 O (n)，适合超大文件外排序。

堆排序 Heap Sort
构建大顶堆，堆顶是最大值，循环取出堆顶再调整堆。
不稳定；O (nlogn)，原地排序空间 O (1)；海量数据 TopK 专用。

三、线性排序 O (n)（特殊限定条件，简单了解）
计数排序 Count Sort
要求数值范围小，统计每个数字出现次数，按次数回填。
稳定、O (n)；只能整数、值域不能太大。
基数排序 Radix Sort
按个位、十位、百位依次计数排序，从低位到高位。
稳定、O (n)；适合数字 / 字符串批量排序。

### 1.两数之和 LeetCode 1
给定一个整数数组nums和一个整数目标值target，请你在该数组中找出和为目标值target的那两个整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

示例 1：
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。

示例 2：
输入：nums = [3,2,4], target = 6
输出：[1,2]

示例 3：
输入：nums = [3,3], target = 6
输出：[0,1]

方法一：暴力枚举
思路及算法
最容易想到的方法是枚举数组中的每一个数 x，寻找数组中是否存在target - x。
当我们使用遍历整个数组的方式寻找target - x 时，需要注意到每一个位于x之前的元素都已经和x匹配过，因此不需要再进行匹配。
而每一个元素不能被使用两次，所以我们只需要在x后面的元素中寻找target - x。
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (nums[i] + nums[j] == target) {
                    return new int[]{i, j};
                }
            }
        }
        return new int[0];
    }
}
```

### 2.三数之和 LeetCode 15
给你一个整数数组 nums ，判断是否存在三元组[nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，
同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。
注意：答案中不可以包含重复的三元组。

示例 1：
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

示例 2：
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。

示例 3：
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。
